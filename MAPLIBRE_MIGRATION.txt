JustFly MapLibre migration: current implementation and cache simplification

The original migration is committed. This follow-up removes its osmdroid cache
compatibility layer and uses MapLibre Android 13.6.1 defaults, as requested.

Caching
MapLibre manages its own ambient resource cache, default location, eviction,
HTTP freshness and automatic database packing. Its documented default ambient
cache limit is 50 MB. The application does not override these settings or install
a custom HTTP client.
Documentation:
https://maplibre.org/maplibre-native/android/api/-map-libre%20-native%20-android/org.maplibre.android.offline/-offline-manager/set-maximum-ambient-cache-size.html
https://maplibre.org/maplibre-native/android/api/-map-libre%20-native%20-android/org.maplibre.android.offline/-offline-manager/index.html

Aviation MBTiles remain SQLite databases in the app-data files/osmdroid/maps directory.
The loader discovers .mbtiles files there without requiring specific filenames.
MapLibre reads their tiles directly. Their data is not imported into a secondary
cache, copied, converted, or downloaded. Permanent offline aviation coverage
depends on these MBTiles, independently of the evictable ambient cache.
The optional OpenTopo raster source uses the SDK's normal download/cache path.
An ambient cache is temporary and does not guarantee every previously visited
online tile remains available indefinitely.

No osmdroid cache.db import, old cache key decoding, converted Mapnik/OpenTopo
MBTiles layers, custom cache path, legacy cache fingerprint/staging machinery,
or osmdroid HTTP expiration/header/thread overrides remain.
Old cached files or stored settings are no longer used; this code change does
not delete previously stored files on the user's device.
MapPreferences resolves context.getFilesDir()/osmdroid/maps directly, without
path probing or filename validation. osmdroid.basePath and osmdroid.cachePath
are no longer read or written. The existing zoom animation preference remains.
MapTileOverlays validates readability and the SQLite tiles table, reporting
missing maps or invalid databases explicitly. Basename-based overlap ordering
is retained, including for the existing lo/lh/lj files.

Dependencies
Removed the application's explicit OkHttp dependency/catalog entries.
MapLibre retains its own transitive OkHttp dependency with no version upgrade.
MapLibre 13.6.1 and all unrelated dependency/build versions remain unchanged.
No osmdroid library dependency is present.
Java 17, AGP 9.3.2, Gradle 9.5.0, minSdk 30 and compile/target SDK 34 are unchanged.

Architecture and functionality retained from the committed migration
MapSurfaceView owns MapLibre's map view. MapController isolates SDK rendering,
projections, north-up camera, aircraft/accuracy/heading layers and lifecycle.
GeoCoordinate/AirspaceGeometry adapt the existing OpenAir domain geometries.
OpenAir parsing/models, circle/arc calculations, aircraft resource and original
control artwork remain unchanged. Aviation layers remain offline; optional
OpenTopo displays the existing airspace boundaries.
GPS repository/HUD, GPX recording/generation/naming/storage, GPX share/delete UI,
FileProvider/manifest, layouts and unrelated preferences are unchanged here.
The osmdroid artwork license is retained because the original icons are retained.
